# Procesamiento de Imagen del Santuario de Monserrate con Pillow

## 📌 Descripción

Este proyecto presenta el uso de la biblioteca Pillow en Python para el procesamiento digital de imágenes, aplicado al Santuario de Monserrate, símbolo cultural, histórico y religioso de Bogotá, Colombia.

El programa realiza:

- Apertura de una imagen del Santuario de Monserrate.
- Visualización de sus propiedades (tamaño, formato y modo).
- Redimensionamiento de la imagen.
- Conversión a escala de grises.
- Adición de un texto descriptivo cultural.
- Generación de una nueva imagen procesada.

Este trabajo demuestra cómo la programación puede utilizarse como herramienta para la difusión y valorización del patrimonio cultural colombiano.

---

## 📚 Biblioteca utilizada

**Pillow** es una biblioteca de Python utilizada para abrir, manipular y guardar imágenes en distintos formatos como PNG, JPG, BMP y GIF.

Es ampliamente empleada en procesamiento digital de imágenes y desarrollo de aplicaciones gráficas.
